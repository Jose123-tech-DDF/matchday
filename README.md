# Matchday on Vercel

This project includes your weekly planner and a server endpoint for La Liga scores and available player details.

1. Extract the ZIP and open a terminal in the extracted project folder (the folder containing index.html and vercel.json).
2. Run `npx vercel login` and complete sign-in in your browser.
3. Run `npx vercel --prod`.
4. Choose your Vercel account, create a new project named matchday, use the current directory, and keep the supplied settings.
5. Open the Production URL printed by Vercel.

No build command or API key is needed for the current feed. ESPN feed availability is not guaranteed. Exact live player coordinates and current ball holder are not provided by this feed. Checklist progress is saved per browser and will begin separately on the new Vercel URL. Use Change background to select your image.
